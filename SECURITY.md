# Security Policy

## Supported versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Use GitHub's private vulnerability reporting for this repository:

<https://github.com/OsamaElnagar/filament-liquid-glass/security/advisories/new>

Include:

- the affected version(s),
- a minimal reproduction (panel config + steps),
- the impact you believe it has.

You can expect an initial response within a few days. Once a fix is released, the advisory will be published with credit if you want it.
